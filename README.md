# ЛР 2.1 — Разработка графического интерфейса приложения

Дисциплина: «Проектирование и программирование мультимедийных приложений».
**Вариант 1** (номер в журнале 20: `20 % 5 + 1 = 1`) — простое окно с кнопками.

| Параметр | Значение |
| --- | --- |
| Заголовок окна | «Медиатек» |
| Элементы | 3 кнопки: «Открыть файл», «Сохранить», «Выход» |
| Поведение | нажатие каждой кнопки выводит сообщение в консоль; «Выход» закрывает окно |

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | главное окно приложения на PyQt6 |
| `requirements.txt` | зависимости Python |
| `.gitignore` | исключения для Git |
| `INSTRUCTIONS.md` | пошаговая инструкция по выполнению |

## Требования

- Python 3.8+
- PyQt6 6.4+

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```
